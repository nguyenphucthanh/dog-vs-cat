# Chó vs Mèo

Game bắn pháo 3D theo lượt, nhiều người chơi trên web. Xem kế hoạch tại [plan.md](plan.md).

## Chạy local

```bash
npm install
npm run dev
```

Lần đầu, `convex dev` sẽ yêu cầu đăng nhập Convex, tạo deployment và ghi URL vào `.env.local`.

## Lệnh

- `npm run dev`: chạy Next.js và Convex
- `npm run build`: typecheck và build
- `npm run lint`: ESLint
- `npm run format`: Prettier
